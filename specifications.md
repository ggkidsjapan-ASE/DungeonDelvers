Game Design ideas

Central Screen on smartboard to track adventures
Groups (system) playable on iPads (1 to a group)
Maps are hidden in the right and revealed as they move around the map
Key to exit on each floor
Ideally first person view or sprites moving along the dungeon
Beastiary page (prepopulated)
Save system for players and Guests (Random) - uses a code to reload data
Items i.e. Health / Rez / Damage items (Chance to break)
Player can check items / beastiary / map / bounties in beastiary
Battle system turn based with Attack / items / run (fails) Heal for healers / steal for thief / 
Stats: HP (based on class) , Strength(damage), Dex (Hit Chance 50% min), Speed(Evasion) set base stats for each class
Level up at end of battle small stat boost
Character is whole group
Classes: Warrior (Tank/Block), Thief (Steal/Mug), Archer(Dual Shot), Mage(Heal/Damage)
